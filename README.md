# 🩸 Red & Black — modèle de README de profil GitHub

Un thème **rouge et noir animé** pour ton profil GitHub. Les bannières sont des SVG hébergés dans ton dépôt : elles s'affichent aussi sur mobile.

*A red & black animated GitHub profile README template. Banners are self-hosted SVGs that also work on the mobile app.*

</div>

<img src="assets/divider.svg" width="100%" alt=""/>

## ✨ Ce que tu obtiens

- Bannière animée : dégradé qui respire, reflet lumineux, titre qui pulse, 3 phrases qui défilent
- Séparateurs et pied de page animés
- Sections prêtes : à propos, stack, projets, stats, contact
- Aucun service externe pour le design (seuls les badges et cartes de stats en utilisent)

## 🚀 Utilisation

1. Crée un dépôt public nommé **exactement comme ton pseudo GitHub** (par ex. `monpseudo/monpseudo`).
2. Copie dans ce dépôt le dossier `assets/` et le fichier `template/README.md`, que tu renommes en `README.md` à la racine.
3. Remplace partout `TON_PSEUDO` par ton pseudo.
4. Ouvre `assets/header.svg` et change le texte `TON PSEUDO` ainsi que les 3 phrases qui défilent.
5. Commit : ton profil est mis à jour.

## 🎨 Personnaliser les couleurs

| Rôle | Couleur |
| --- | --- |
| Noir | `#0d0000` / `#1a0000` |
| Rouge sombre | `#8B0000` |
| Rouge vif | `#E01B1B` / `#ff3b3b` |

Remplace ces valeurs dans les fichiers `assets/*.svg` et dans `template/README.md` pour changer de thème.
